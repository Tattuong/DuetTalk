# DuetTalk

Two people talk on one screen. One half is turned around so you can type, then hand the phone across.

Package: `com.DuetTalkMNG.DuetTalk`

Remote config: [N305.json](https://api2.blwsmartware.net/N305.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `dt_pack_1` … `dt_pack_10` | Consumable coins |
| `dt_remove_ads` | Non-consumable |
| `dt_pro` | Non-consumable, more than 8 saved phrases |

Chats and saved phrases stay on the device. No account.
